# Swap Jolee and Bastila Classes

Game: KOTOR 1

Author: Dodrari Kaan

Version: 1.0.0

GitHub: https://github.com/danielstegink/Kotor.SwapJoleeAndBastilaClasses



It occurred to me that Bastila's and Jolee's classes don't make a lot of sense for them. Jolee is an ex-Padawan who has tried just about every career path in the galaxy. Meanwhile, Bastila is a (relatively) sheltered Jedi prodigy with unique Force powers. This mod swaps their classes, and it slightly modifies their stats and abilities. I didn't change their starting lightsabers to ensure compatibility with any mods that modify those lightsabers.



## Instructions

1. If you have any mods that modify Bastila's and Jolee's character files, such as offthegridmorty's "Bastila Has TSL Battle Meditation", install those first
2. Use the TSLPatcher



## Permissions

Use this mod however you want. Just make sure to credit me.



## Compatibility

This mod uses GFF to modify Bastila's and Jolee's classes and abilities. It may overwrite any changes made to these files by other mods, but it should be compatible with any mods that don't have any overlapping changes on these files.
